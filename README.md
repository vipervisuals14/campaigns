# campaigns

Viper Visuals — photographic compositing knowledge base and project archive.

This repository is the permanent working knowledge base for the Viper Visuals master compositing agent. It contains general compositing knowledge, technique references, per-project materials and the correction/approval history that drives continuous improvement.

## Structure

| Path | Contents |
|------|----------|
| `COMPOSITING_KNOWLEDGE/` | Master instructions, core knowledge, visual standards, approved references, corrections log, project history |
| `PROJECTS/PROJECT_XXX/` | Per-project source images, environment references, approved composites and notes |
| `TECHNIQUES/` | Deep technical references: perspective, lighting, shadows, texture preservation, environmental reconstruction |

## Rules of use

- Original photographs are the source of truth and are never overwritten.
- Approved composites are visual benchmarks and are never overwritten.
- All meaningful corrections and successful techniques are written back to `COMPOSITING_KNOWLEDGE/`.
- General knowledge lives in `COMPOSITING_KNOWLEDGE/` and `TECHNIQUES/`; project-specific material lives in `PROJECTS/`.

See `COMPOSITING_KNOWLEDGE/MASTER_INSTRUCTIONS.md` for the full operating doctrine.
