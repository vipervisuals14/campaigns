# Visual Standards

## Global standards

- Target authentic professional photography, not a visibly generated or stylized result.
- Preserve original subject identity, pose, proportions, clothing, accessories, skin, hair and framing. Alter only what the composite requires, preferably the environment.
- Prioritize perspective and physical integration before cinematic polish. Match the subject's ground plane, relative scale, camera viewpoint, light and shadow behavior to the scene.
- Retain full source resolution, texture and grain; avoid unnecessary upscaling, denoising, smoothing, sharpening, HDR and repeated JPEG saves.
- Keep original inputs separate and untouched. Save work as a separate draft; obtain explicit approval before classifying an image as approved.
- Backgrounds should represent the same physical location and visual language without reusing a fixed plate where the source camera perspective differs.

## User-preferred quality benchmark

The user supplied `COMPOSITING_KNOWLEDGE/References/boxing-gym-editorial-user-benchmark.png` as a strong quality/style target and asked for future work to match it. Read it as a style benchmark, not as source imagery or a fixed background plate. The qualities to carry forward are portrait editorial framing, a large naturally integrated subject, moody warm industrial-gym atmosphere, soft directional/window light, realistic tonal depth, and a softly defocused but legible environment. Avoid obvious cutout edges, flat pasted-on lighting, blank inpaint patches, and unnecessary wide framing when the source calls for portrait composition. Preserve each new original subject exactly and adapt the environment to that photograph's own camera view. This is a user-confirmed style preference; it does not approve any existing draft or make every creative choice universal.
