# APPROVED REFERENCES

**Purpose:** Visual benchmarks. Approved composites define the standard for their project and inform future work.
**Last updated:** 2026-11-18

---

## How to use this file

When a composite is approved:

1. Copy the final file to `PROJECTS/PROJECT_XXX/Approved_Composites/`.
2. Add a row below with the required fields.
3. Record **what made it successful** — environment, lighting, colour treatment, perspective, materials, texture, subject integration, overall realism.
4. Tag each lesson as **Permanent** (applies to all projects) or **Project-specific**.
5. Never overwrite an approved original or reference image. New versions get a new filename.

## Field definitions

- **ID:** `REF-001`, `REF-002`, …
- **Project:** Link to `PROJECTS/PROJECT_XXX/Project_Notes.md`.
- **File:** Path within `Approved_Composites/`.
- **What made it successful:** Concise technical notes, not vague praise.
- **Classification:** Permanent preference vs. project-specific decision.
