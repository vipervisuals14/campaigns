**Purpose:** Every meaningful correction, its root cause, and the resolution. This is the primary engine of workflow improvement.
**Last updated:** 2026-11-18

---

## How to use this file

For every piece of feedback:

1. Log the issue with a unique ID (`COR-001`, `COR-002`, …).
2. Identify the **underlying technical cause**, not just the surface symptom.
3. Record the correction applied and the successful solution.
4. Link to any technique doc updated (`TECHNIQUES/...`).
5. Mark status: `Open` → `Resolved` → `Verified`.
6. Add the lesson to `COMPOSITING_KNOWLEDGE.md` §7 once confirmed.

## Diagnostic map (from Master Instructions §08)

| Feedback | Investigate |
|---|---|
| Perspective is wrong | Camera position, lens perspective, ground-plane alignment, horizon placement, vanishing points |
| Image looks plastic | Texture loss, subject regeneration, excessive processing, smoothing, repeated generation |
| Lighting does not match | Light direction, intensity, colour temperature, ambient illumination, shadow placement |
| Environment does not look like the same location | Environmental geometry, architectural consistency, materials, spatial relationships, camera perspective |
